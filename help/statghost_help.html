STATghost · v0.4.9

Quick manual

Copy → local R / Python / Julia → text and plot. A sniper, not an IDE.

30 seconds

  1. Unzip so statghost.exe and statghost_rhost.exe stay together (rhost only needed for R.dll).
  2. Run statghost.exe (toolbar, top-right).
  3. Under Set → Session, pick R, Python, or Julia (and path if needed).
  4. Click Idle → Armed.
  5. In another app: select code and press Ctrl+C — or use the optional Capture hotkey with no selection (see Clipboard).
  6. Read the result under Console / Plot.

Traffic lights

  • Set — preferences (Appearance includes toolbar icon size 16 px / 24 px).
  • Idle / Armed — clipboard sniper on/off.
  • Kill — stop this app’s current engine child.
  • Panel — show/hide the output window (Separados float bar only; not duplicated on the Unidos tab strip).
  • Clear — clear console and plot.
  • Unite/Split — Separados ↔ Unidos (rightmost on the panel tab bar; switch glyph).

Click the icon → Help / About / OS global hotkeys / Quit. Status shows engine badge and HK: on|off. Drag the bar by the background. Chrome glyphs are flat monochrome, tinted for the active theme.

Engines (R / Python / Julia)

  • Under Set → Session (Path | Options) pick the language.
  • R: home (empty = newest); Use {Rterm.exe | R.dll}. R.dll uses sidecar statghost_rhost.exe (GUI never loads R.dll).
  • Python: interpreter path; Options — Matplotlib window, prefetch imports.
  • Julia: path (empty = discover / juliaup); Options — show GR window when relevant. Plot panel PNGs use the same high-res size class as R/Python (Plots.jl savefig of current()).
  • R Options: show rgl window when relevant.
  • Status badge examples: R.dll · 4.5.0, Python · 3.12, Julia · 1.11, or idle.

Kill

  • Kill ends only STATghost’s current child — Rterm / rhost / Python / Julia — not RStudio or other IDEs.
  • Works mid-eval. Toolbar returns to green Idle; click Arm for a fresh session.
  • Changing language / paths / R Use while running kills that session first.

Clipboard

  • When Armed, eval runs only if clipboard text changes.
  • Copying the same selection again does not re-run (dedup).
  • Current line without selection: under Set → Hotkeys → Capture, record an optional alternative chord. That hotkey asks the foreground app to Copy, then STATghost evaluates. In many editors (VS Code, Notepad++, RStudio, CudaText, …), Copy with no selection sends the current line — step a script line by line without selecting. If the source app does nothing without a selection, select text as usual (or use Ctrl+C when Armed).
  • After each eval, Console scroll can sit the new chunk at Middle (default), Top, or Bottom (Set → Behavior).
  • Meta notices go to the console meta stream; status bar shows engine badge + tips.

Panel

  • Console — read-only ATSynEdit with Cuda lexers from the lexer/ folder beside the EXE (R / Python / Julia). Ctrl+Tab / Shift+Ctrl+Tab — Console ↔ Plot. The active tab highlight follows the page after eval focus (Auto / Console / Plot). Echo prompts: R >/+, Python >>>/..., Julia julia>/julia| (continuation is classroom-style). Under the Console: small tweaks only inside an echoed input chunk (prompt locked; not a free editor), then Ctrl+Enter to re-eval (Settings → Shortcuts; Capture stays Ctrl+C when Armed). C+Up/C+Down (hold letter C, not Ctrl) jump previous/next input cell.
  • Chrome (Separados | Unidos) — Unite/Split button on the tab bar (rightmost). Separados: floating traffic bar + panel; lights only on the float (panel shows the mode toggle). Form único / Unidos (default): one window — strip on the tab bar (brand | Set | Arm | Kill | Clear); floating bar hidden while the panel is open. Horizontal magnet: shared left edge; vertical: tops aligned, rail to the left of the panel.
  • After eval, focus is Auto by default: Plot if this eval drew graphics, else Console (Set → Behavior to force Console, Plot, or return to source).
  • Plot: high-res PNG (R, Python Matplotlib, Julia Plots.jl); zoom and history ← / →; erase-history control after the N/M counter; optional PDF (R); Size matches pane (default on) and PNG DPI slider (soft green → dark blue, default 288) shared by TImage and AT Gaps. Set → Plot panel → Display chooses Lazarus TImage (default) or ATSynEdit Gaps; switch anytime.
  • Bookmarks: Ctrl+Shift+0..9 / Ctrl+0..9.

Settings

  • Appearance — opacity; Toolbar orientation (Separados only — unmarked/disabled under Form único); Layout (Separados | Form único, default Form único; same as Unite/Split); Icon size (16 px / 24 px, default 24); theme. Chrome uses flat monochrome glyphs tinted for the active theme.
  • Behavior — after-eval focus (Auto / Console / Plot / source); Console scroll after eval (Middle / Top / Bottom).
  • Session — Path | Options per language; Ctrl+Tab / Shift+Ctrl+Tab cycle R|Python|Julia (does not change Active Use radios).
  • Hotkeys — OS global: Capture / Arm / Focus / Clear console via Record and Clear|Reset. Capture default stays Ctrl+C; optional alternative chord (Copy in source → eval; often current line with no selection). Ctrl+L clears Console text only; toolbar Clear still wipes console + plot. Alt+Space is rejected (Windows system menu).
  • Shortcuts — Console-local (not OS RegisterHotKey): Ctrl+Enter re-evals the input cell at the caret; C+Up/C+Down (hold letter C, not Ctrl) jump previous/next input cell (both configurable).
  • Editor — font, highlighter, view options (Settings Syntax preview mirrors ATSynEdit Console chrome; live Console uses ATSynEdit + lexer/). Under Syntax → Console: chrome Moldura (frame) (default) or Zebrado (zebra); optional frame colour (theme or custom). Moldura outlines echoed input only. Ctrl+Tab / Shift+Ctrl+Tab cycle Font|Syntax.
  • Plot panel — Display (TImage | AT Gaps), history ←/→ + erase-history, PDF, Size (match pane + PNG DPI slider).

Hotkeys

  • Ctrl+Alt+R — Arm / Idle (default; Record under Set → Hotkeys).
  • Ctrl+C — capture via system Copy (when Armed).
  • Optional Capture alternative (Record under Set → Hotkeys) — Copy in the foreground app, then eval (current line without selection in many editors).
  • Ctrl+Alt+F — Focus mode toggle (default).
  • Ctrl+L — Clear Console text only (default; R console).
  • Brand menu OS global hotkeys — when off, Arm / alt-capture / focus / clear chords are unregistered (HK: off). Ctrl+C sniper while Armed still works.

Shortcuts (Console)

Local to the Console panel (not OS RegisterHotKey). Set → Shortcuts.

  • Ctrl+Enter — re-eval the input cell at the caret.
  • C+Up / C+Down — previous / next input cell (hold letter C, not Ctrl — keeps Ctrl+arrows for scroll).

Automated checks (lab)

  • Smoke: statghost.exe --smoke → statg5_report.txt (RESULT=BOK).
  • SR / SP / SJ / ST: whole-file samples — --sr (R rterm+rdll), --sp (Python), --sj (Julia), --st / --tf-samples (all) → statg_sr|sp|sj|st_report.txt. Or: powershell -File src/tf_samples.ps1 [-Mode ST|SR|SP|SJ].
  • Dev smokes (SRD|SPD|SJD|STD): random ~20% of scripts per lane (--srd…--std). Prefer these while iterating.
  • BENCH: same OLS lesson in all four environments (Rterm.exe | R.dll | Python | Julia) — --bench → w_log/benchmark.txt; powershell -File benchmark/run_bench.ps1.

Troubleshooting

  • No output → Armed? New clipboard text? Correct Session language? Badge not idle?
  • No plot → did this chunk draw (plot, Matplotlib, Plots.jl, …)?
  • R.dll won’t start → is statghost_rhost.exe next to the app? Is R.dll under R home? Or switch Use to Rterm.exe.
  • Python / Julia not found → set path under Session → Path, or leave empty for discover.
  • Stuck eval → press Kill, then Arm again.
  • Hotkey clash → turn off OS global hotkeys (Ctrl+C when Armed remains).
  • Taskbar icon looks outdated after an update → unpin / repin statghost.exe (Windows caches MAINICON).
