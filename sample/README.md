# Sample scripts for STATghost (Arm → Ctrl+C)

**Primary purpose: teaching.** Every script is classroom material for the
progressive sniper REPL (R | Python | Julia).

| Folder | Language |
|--------|----------|
| [`R/`](R/) | R |
| [`Python/`](Python/) | Python |
| [`Julia/`](Julia/) | Julia |

## How to use

1. Start STATghost and **Arm**.  
2. Open a sample file, select one chunk (blank lines separate chunks), **Ctrl+C**.  
3. Prefer **one chunk at a time** the first time through a lesson.

## Style (when adding scripts)

1. `# Objective: …` (EN) on the first line.  
2. Short EN step comments where useful.  
3. Blank lines = intentional sniper **chunks**.  
4. Readable calls; optional deps should print `SKIP …`.  
5. Update that language folder’s README table.

See each folder’s table for plots and optional packages.
