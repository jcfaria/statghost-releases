# Linux

Download the latest **Linux x86_64** archive from:

https://github.com/jcfaria/statghost-releases/releases

Typical contents:

- `statghost` — gtk2 binary  
- `statghost_py_repl.py` / `statghost_jl_repl.jl` — REPL drivers  
- `png/` — UI glyphs  

Make executable if needed: `chmod +x statghost`, then run from a terminal.

Binaries are attached to GitHub Releases — not stored in this Git tree.
